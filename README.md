# Vincit Fantasy Manager ⚽

Aplicació web tipus **Fantasy Football** personalitzada exclusivament per a la comunitat i equips del club de futbol sala **CE Vincit - Sant Gervasi**.

🌐 **Accedeix a l'aplicació web:** [https://fantasyvincit.vercel.app/](https://fantasyvincit.vercel.app/)

---

## 🌟 Què és Vincit Manager?

Cada participant actua com a **mànager** del seu propi equip:
- **Cinc Titular & Plantilla:** Confecciona el teu quintet inicial de futbol sala fitxant jugadors reals dels diferents equips del club.
- **Mercat & Subhastes:** Negocia fitxatges, rep ofertes directes o participa en subhastes oficials gestionades pel club.
- **Puntuacions Reals:** Suma punts cada jornada segons el rendiment real dels jugadors als seus partits (gols, assistències, porteries a zero, parades i valoracions dels entrenadors).
- **Classificació en directe:** Competeix contra la resta de mànagers per liderar el rànquing general de la temporada.

---

## 🛠️ Tecnologies Utilitzades

- **Frontend:** React, Vite, Tailwind CSS
- **Backend & Base de Dades:** Supabase (PostgreSQL, Realtime & Auth)
- **Desplegament:** Vercel

---

## 🚀 Desenvolupament Local

Si vols executar el projecte en local:

```bash
# 1. Instal·lar dependències
npm install

# 2. Configurar variables d'entorn (.env)
# VITE_SUPABASE_URL=la_teva_url_supabase
# VITE_SUPABASE_ANON_KEY=la_teva_clau_anonima

# 3. Iniciar el servidor de desenvolupament
npm run dev
```
